### ✦ Primeros pasos

- [Visual Studio Code](https://code.visualstudio.com/) `EN` — El editor de código estándar de la industria. Ligero, gratuito y con interfaz en español.
- [freeCodeCamp en español](https://www.freecodecamp.org/espanol/) `ES` — Cursos y artículos completos desde cero, con certificaciones gratuitas.
- [CS50x de Harvard](https://cs50.harvard.edu/x/) `EN` — La introducción a las ciencias de la computación más famosa del mundo. Gratis y a tu ritmo.

### ✦ Git y GitHub

- [Pro Git](https://git-scm.com/book/es/v2) `ES` — El libro oficial de Git, completo y traducido al español.
- [Learn Git Branching](https://learngitbranching.js.org/?locale=es_ES) `ES` — Aprende ramas, merges y rebase de forma visual e interactiva.
- [Oh Shit, Git!?!](https://ohshitgit.com/es) `ES` — Cómo salir de los errores más comunes de Git, explicado sin rodeos.
- [GitHub Skills](https://skills.github.com/) `EN` — Cursos prácticos dentro de GitHub, con repositorios reales.
- [First Contributions](https://github.com/firstcontributions/first-contributions) `ES` — Haz tu primer Pull Request paso a paso (incluye guía en español).

### ✦ Datos y SQL

- [SQLBolt](https://sqlbolt.com/) `EN` — Lecciones interactivas de SQL directo en el navegador. Cero instalaciones.
- [SQLZoo](https://sqlzoo.net/) `EN` — Ejercicios de SQL por niveles, de lo básico a consultas complejas.
- [Select Star SQL](https://selectstarsql.com/) `EN` — Un libro interactivo que enseña SQL con un dataset real.
- [Kaggle Learn](https://www.kaggle.com/learn) `EN` — Microcursos de Python, pandas, SQL, visualización y machine learning.
- [Documentación de Power BI](https://learn.microsoft.com/es-es/power-bi/) `ES` — La guía oficial de Microsoft para crear tableros y reportes.
- [Documentación de SQL Server](https://learn.microsoft.com/es-es/sql/) `ES` — Referencia oficial de T-SQL y SQL Server.

### ✦ Python

- [Tutorial oficial de Python](https://docs.python.org/es/3/tutorial/) `ES` — El tutorial de la documentación oficial, traducido por la comunidad.
- [Automate the Boring Stuff](https://automatetheboringstuff.com/) `EN` — Python práctico para automatizar tareas del día a día. Libro completo gratis en línea.

### ✦ Desarrollo web

- [MDN Web Docs](https://developer.mozilla.org/es/) `ES` — La referencia de HTML, CSS y JavaScript que usa toda la industria.
- [The Odin Project](https://www.theodinproject.com/) `EN` — Ruta completa de desarrollo web full stack, basada en proyectos.

### ✦ Roadmaps

- [Roadmap: Data Analyst](https://roadmap.sh/data-analyst) `EN` — Qué aprender y en qué orden para trabajar en análisis de datos.
- [Roadmap: SQL](https://roadmap.sh/sql) `EN` — Todos los temas de SQL, de lo básico a lo avanzado.
- [Roadmap: Git y GitHub](https://roadmap.sh/git-github) `EN` — El mapa completo para dominar el control de versiones.

### ✦ Carrera y entrevistas

- [Tech Interview Handbook](https://www.techinterviewhandbook.org/) `EN` — Guía gratuita para preparar CV, entrevistas técnicas y negociación.

### ✦ Datasets para practicar

- [datos.gob.mx](https://datos.gob.mx/) `ES` — Datos abiertos del gobierno de México, ideales para tus primeros proyectos.
- [Kaggle Datasets](https://www.kaggle.com/datasets) `EN` — Miles de datasets públicos de todos los temas.
